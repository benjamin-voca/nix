# Clustta Studio

Clustta Studio is deployed at [clustta.voltrum.co](https://clustta.voltrum.co)
through the existing Cloudflare Tunnel and nginx ingress.

## Deployment

The declarative manifests are generated by:

- `modules/outputs/bootstrap/clustta.nix`
- `modules/outputs/default.nix`

The deployment uses the pinned `eaxum/clustta:0.4.39` image in private mode.
It stores state in three Ceph-backed PVCs:

| PVC | Size | Contents |
| --- | ---: | --- |
| `clustta-data` | 5 GiB | Users, sessions, server state |
| `clustta-projects` | 50 GiB | Project metadata and Compact chunks |
| `clustta-storage` | 100 GiB | Deflated project blobs |

The PVCs allow expansion as project storage grows.

## Operations

```bash
kubectl -n clustta get pods,pvc,ingress
kubectl -n clustta logs -f deployment/clustta
curl https://clustta.voltrum.co/ping
```

The first private-mode administrator is created by the upstream image with the
default credentials `admin@email.com` / `password`. Change this password
immediately on first login.

Back up all three PVCs together. A Deflated project is not recoverable from its
`.clst` metadata alone; its matching contents in `clustta-storage` are also
required.
